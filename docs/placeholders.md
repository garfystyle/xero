# Плейсхолдеры

[Xero](../README.md) · [Действия](actions/README.md) · [События](events.md) · [Игровые значения](values.md) · [Плейсхолдеры](placeholders.md) · [Частицы, зелья, звуки](effects.md) · [Компоненты](components.md)

Работают внутри текста. Две формы: `%player%` и `%var(Имя)` — у функции после скобки `%` не ставят.

```kotlin
send_message("Привет, %player%! Монет: %var_save(coins)")
```

## Цели

| Запись | Что значит |
|:--|:--|
| `%player%` | Ник игрока, который вызвал событие или был задействован в процессе с маркером "Каждая цель в выборке". |
| `%player_uuid%` | То же, что и %player%, но вместо ника UUID игрока. |
| `%entity%` | Имя существа, которое вызвало событие (например, существо получает урон), или участвовало в нём (например, игрок подбирает опыт), или было задействовано в процессе с типом цели "Каждая цель в выборке". Существо может оказаться игроком, если в событии игрока не участвуют другие существа или процесс был вызван для игрока. |
| `%entity_uuid%` | То же, что и %entity%, но вместо ника UUID сущности. |
| `%victim%` | Имя жертвы в событии (существо/игрок, над которым производилось действие). |
| `%victim_uuid%` | UUID жертвы в событии. |
| `%damager%` | Имя атакующего в событии (существо/игрок, наносящее(-ий) урон другой цели). |
| `%damager_uuid%` | UUID атакующего в событии. |
| `%shooter%` | Имя стрелка в событии (существо/игрок, стрельнувшее(-ий) снарядом в цель). |
| `%shooter_uuid%` | UUID стрелка в событии. |
| `%killer%` | Имя убийцы (существо/игрок) в событии смерти. |
| `%killer_uuid%` | UUID убийцы в событии смерти. |
| `%selected%` | Имя первой цели в текущей выборке. |
| `%selected_uuid%` | UUID первой цели в текущей выборке. |
| `%display_name%` | То же, что и %entity%, но если существом является игрок, то заменяется на ник игрока с префиксом и суффиксом. |
| `%uuid%` | Сокращение плейсхолдера %entity_uuid%. |

## Символы

| Запись | Что значит |
|:--|:--|
| `\n` | Символ новой строки. |
| `%space%` | Пробел. |
| `%empty%` | Пустая строка. |

## Функции

| Запись | Что значит |
|:--|:--|
| `%var()` | Значение игровой переменной, имя которой указано в круглых скобках. |
| `%var_local()` | То же, что и %var(), но для локальных переменных. |
| `%var_save()` | То же, что и %var(), но для сохранённых переменных. |
| `%var_line()` | То же, что и %var(), но для строчных переменных. |
| `%length()` | Получает длину списка или словаря, имя которого указано в скобках. |
| `%length_local()` | то же, что и %length(), но для локальных списков и словарей. |
| `%length_save()` | то же, что и %length(), но для сохранённых списков и словарей. |
| `%length_line()` | То же, что и %length(), но для строчных списков и словарей. |
| `%index()` | Получает значение из списка. Имя списка и индекс значения указываются в скобках через запятую. |
| `%index_local()` | То же, что и %index(), но для локальных списков. |
| `%index_save()` | То же, что и %index(), но для сохранённых списков. |
| `%index_line()` | То же, что и %index(), но для строчных списков. |
| `%entry()` | Получает значение из словаря. Имя словаря и ключ значения указываются в скобках через запятую. |
| `%entry_local()` | То же, что и %entry(), но для локальных словарей. |
| `%entry_save()` | То же, что и %entry(), но для сохранённых словарей. |
| `%entry_line()` | То же, что и %entry(), но для строчных словарей. |
| `%math()` | Значение алгебраического выражения в круглых скобках. Числа: десятичные 1, 2.5; экспоненциальные 1e10, 1.2E-3; двоичные 0b01; восьмеричные 0o01234567; шестнадцатеричные 0x0123456789ABCDEF. Константы: PI — число Пи, E — число Эйлера. Переменные — по имени, по правилам Java: буквы, цифры (не в начале), _, $. Тип выбирается по локальности снизу вверх: строчная, локальная, игровая, сохранённая. %math(a + b) — сумма a и b: есть строчные a и b — возьмёт их, иначе ищет в более глобальных. Через %var имя и тип любые, но это медленнее и загромождает выражение, а по сути просто подстановка текста — лучше оборачивать в скобки: %math((%var(a)) + 1). Функции: abs(x) - модуль числа; sqrt(x) - квадратный корень; cbrt(x) - кубический корень; ceil(x, y) - округление числа x в большую сторону с y знаков после запятой (по умолчанию y = 0); floor(x, y) - округление числа x в меньшую сторону с y знаков после запятой; sin(x), cos(x) - тригонометрические функции, x в градусах; round(x, y) - округление числа x с точностью y; pow(x, y) - возведение числа x в степень y; min(x, y), max(x, y) - меньшее и большее из двух чисел; sign(x) - знак числа (1, -1, 0); atan2(y, x) - получение арктангенса двух значений; root(a, b) - получение корня b степени от a; clamp(x, min, max) - ограничить число x в диапазоне от min до max; wrap(x, min, max) - обернуть число x в диапазон от min до max; sinr(x), cosr(x) - тригонометрические функции, x в радианах; asin(x) - арксинус числа x; acos(x) - арккосинус числа x. |
| `%val()` | Получает игровое значение, ID которого указано в скобках. |

## Значения

| Запись | Что значит |
|:--|:--|
| `%player_amount%` | Количество игроков в мире. |
| `%entity_count%` | Количество существ в мире (игроки не учитываются). |
| `%entity_amount%` | Альтернативное название для плейсхолдера %entity_count%. |
| `%global_online%` | Количество игроков на сервере. |
| `%online%` | Сокращение для плейсхолдера %global_online%. |
| `%time%` | Текущее время сервера, представленное стандартом ISO-8601. |
| `%worlds%` | Количество онлайн миров игроков. |

## Разное

| Запись | Что значит |
|:--|:--|
| `%damage%` | Количество нанесённого урона в событии. |
| `%random%` | Случайное дробное число, большее или равное 0, но меньшее, чем 1. |
| `%random_uuid%` | Случайно сгенерированный UUID. |
