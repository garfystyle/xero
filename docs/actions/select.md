## Выбрать цель

### Создание выборки

#### `all_players`

**Выбрать всех игроков** — Выбирает всех игроков в мире.

```kotlin
all_players()
```

#### `all_mobs`

**Выбрать всех мобов** — Выбирает всех мобов в мире.

```kotlin
all_mobs()
```

#### `all_entities`

**Выбрать всех сущностей** — Выбирает всех сущностей в мире.

```kotlin
all_entities()
```

#### `player_by_name`

**Выбрать игрока по имени** — Выбирает игрока или игроков по имени или UUID.

```kotlin
player_by_name("текст")
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `name_or_uuid` | текст, до 18 | Имя или UUID цели |

#### `player_by_conditional`

**Выбрать игрока по условию** — Выбирает игроков, если выполняется указанное условие.

```kotlin

```

### Фильтрация выборки

#### `filter_by_distance`

**Отфильтровать выборку по расстоянию** — Оставляет в выборке те цели, которые находятся на расстоянии до местоположения.

```kotlin
filter_by_distance(loc(0, 64, 0), 1)
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `location` | местоположение | Местоположение центра |
| `selection_size` | число | Количество целей |
| `ignore_y_axis` | маркер | Игнорировать ось Y:<br>`true` Игнорировать<br>`false` Не игнорировать |
| `compare_mode` | маркер | Тип сравнения:<br>`nearest` Ближайшие цели<br>`farthest` Дальние цели |

#### `filter_by_conditional`

**Отфильтровать выборку по условию** — Оставляет в выборке те цели, которые подходят под выбранное условие.

```kotlin
filter_by_conditional(x == 1)
```

#### `filter_randomly`

**Отфильтровать выборку случайно** — Оставляет в выборке указанное количество случайных целей.

```kotlin
filter_randomly(1)
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `size` | число | Количество целей |

#### `filter_by_raycast`

**Фильтр рейкастом** — Оставляет в выборке только те цели, в которые попал запущенный луч. Ширина луча работает только на сущностей (увеличивает или уменьшает хитбоксы существ).

```kotlin
x = filter_by_raycast(loc(0, 64, 0), 1, 1, 1)
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `variable` | переменная | Точка конца луча |
| `origin` | местоположение | Начало луча |
| `max_distance` | число | Длина луча |
| `ray_size` | число | Ширина луча |
| `selection_size` | число | Максимальное количество сущностей |
| `consider_blocks` | маркер | Учитывать блоки:<br>`true` Учитывать<br>`false` Не учитывать |
| `ignore_passable_blocks` | маркер | Игнорировать проходимые блоки:<br>`true` Игнорировать<br>`false` Не игнорировать |
| `fluid_collision_mode` | маркер | Игнорировать жидкость:<br>`never` Полностью игнорировать<br>`source_only` Учитывать только источник жидкости<br>`always` Не игнорировать |
