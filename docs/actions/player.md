## Действие над игроком

### Управление инвентарём

#### `give_items`

**Выдать предмет** — Выдаёт игроку предметы из сундука.

```kotlin
give_items(item(stone), 1)
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `items` | предмет, до 17 | Предметы для выдачи |
| `amount` | число | Количество предметов для выдачи |

#### `give_random_item`

**Выдать случайный предмет** — Выдаёт игроку случайный предмет или стак из предметов в сундуке.

```kotlin
give_random_item(item(stone))
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `items` | предмет, до 27 | Предметы для выбора |

#### `player.complete_using_active_item`

**Завершить использование предмета** — Завершает использование текущего предмета в руке с результатом.

```kotlin
player.complete_using_active_item()
```

#### `load_inventory`

**Загрузить сохранённый инвентарь** — Загружает выбранный сохранённый инвентарь.

- Если нет сохранённого инвентаря, инвентарь игрока будет очищен.

```kotlin
load_inventory()
```

#### `replace_items`

**Заменить предметы** — Заменяет указанные предметы в инвентаре на определённый предмет.

```kotlin
replace_items(item(stone), item(stone), 1)
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `replace` | предмет | Заменяющий предмет |
| `items` | предмет, до 28 | Заменяемые предметы |
| `count` | число | Количество предметов для замены |

#### `start_using_item`

**Начать использование предмета** — Начинает использование предмета в указанной руке.

```kotlin
start_using_item()
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `equipment` | маркер | Тип руки:<br>`main_hand` Основная рука<br>`off_hand` Второстепенная рука |

#### `clear_inventory`

**Очистить инвентарь** — Очищает инвентарь игрока.

```kotlin
clear_inventory()
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `clear_mode` | маркер | Режим очистки:<br>`entire` Весь инвентарь<br>`main` Главный инвентарь<br>`upper` Верхний инвентарь<br>`hotbar` Хот-бар<br>`armor` Броня |

#### `clear_items`

**Очистить предметы** — Удаляет все выбранные предметы из инвентаря игрока.

```kotlin
clear_items(item(stone))
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `items` | предмет, до 18 | Предметы для очистки |

#### `clear_ender_chest_contents`

**Очистить содержимое Эндер-сундука** — Очищает предметы в инвентаре Эндер-сундука игрока.

```kotlin
clear_ender_chest_contents()
```

#### `clear_active_item`

**Прервать использование предмета** — Прерывает использование текущего предмета.

```kotlin

```

**Установить броню** — Устанавливает броню игрока.

| `leggings` | предмет | Штаны |
| `boots` | предмет | Ботинки |

#### `set_item_group_cooldown`

**Установить задержку для группы предметов** — Применяет визуальный эффект шкалы задержки для всех предметов указанной группы.

- Задержка будет применена ко всем предметам, которые относятся к указанной группе.

```kotlin
set_item_group_cooldown("текст", 1)
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `key` | текст | Группа предметов |
| `cooldown` | число | Задержка |

#### `set_item_cooldown`

**Установить задержку предмета** — Применяет визуальный эффект шкалы задержки для всех предметов выбранного типа.

- Задержка будет применена ко всем предметам выбранного типа.

```kotlin
set_item_cooldown(1, item(stone), sound(entity.player.levelup))
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `cooldown` | число | Задержка в тиках |
| `item` | предмет | Тип предмета для задержки |
| `sound` | звук | Звук сброса задержки |
