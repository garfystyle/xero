## Действие с переменной

### Присвоение значений

#### `var.remove`

**Очистить переменные** — Очищает значения, которые находятся в переменных.

```kotlin
var.remove(x)
```

|:--|:--|:--|
| `variables` | переменная, до 18 | Переменные для удаления значения |
