## Контроллер

#### `measure_time`

**Замерить время выполнения** — Замеряет время выполнения кода внутри поршней и присваивает результат к переменной.

- Учитывает блоки "Ждать".

```kotlin
measure_time(x) { }
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `variable` | переменная | Переменная для присвоения |
| `duration` | маркер | Формат времени:<br>`nanoseconds` Наносекунды<br>`microseconds` Микросекунды<br>`milliseconds` Миллисекунды |

#### `do_not_run`

**Игнорировать выполнение** — Игнорирует код, находящийся внутри скобок, во время выполнения.

```kotlin
do_not_run() { }
```

#### `isolated_selection`

**Изолировать выборку** — Изолирует выборку внутри скобок.

- Созданная внутри выборка будет активна лишь в рамках скобок.
- При выбранном типе выборки "Проход по выборке", внутри скобок может быть вызвано действие "Возврат" для перехода к следующему значению в выборке.

```kotlin
isolated_selection() { }
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `selection_mode` | маркер | Начальная выборка:<br>`default` По умолчанию<br>`current` Текущая выборка<br>`empty` Пустая выборка<br>`for_each` Проход по выборке |

#### `label`

**Пометить код** — Помечает код между поршнями указанным именем и позволяет его прервать.

- Работает в связке с действием "Выйти из блока с меткой"

```kotlin
label("текст") { }
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `label` | текст | Название метки |

#### `exception`

**Уловить ошибку** — Улавливает ошибку в коде внутри поршней и присваивает её идентификатор к переменной (пример: function_not_found).

- Не улавливает глобальные и критические ошибки.

```kotlin
exception(x) { }
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `variable` | переменная | Переменная для присвоения |
