## Контроль действий

#### `return_function`

**Вернуться до вызова** — Останавливает текущую последовательность блоков кода в функции и возвращает к блоку вызова этой самой функции.

- Возвращает до блока вызова текущей функции в родительской строке.

```kotlin
return_function()
```

#### `call_exception`

**Вызвать ошибку** — Вызывает определённую ошибку с указанным ID и сообщением.

- Рекомендуется использовать это в действии "Уловить ошибку".

```kotlin
call_exception("текст", "текст")
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `id` | текст | ID ошибки |
| `message` | текст | Сообщение ошибки |
| `type` | маркер | Тип ошибки:<br>`warning` Предупреждение<br>`error` Ошибка<br>`fatal` Критическая |

#### `break_label`

**Выйти из блока с меткой** — Прерывает код, помеченный указанным именем.

- Работает с: Действием "Пометить код"

```kotlin
break_label("текст")
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `label` | текст | Название метки |

#### `wait`

**Ждать** — Приостанавливает текущую последовательность блоков кода на определённое время.

- Минимальная задержка - 1 тик; в режиме Тики можно установить только целые числа.

```kotlin
wait(1)
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `duration` | число | Длительность ожидания |
| `time_unit` | маркер | Единица времени:<br>`ticks` Тики<br>`seconds` Секунды<br>`minutes` Минуты |

#### `stop_repeat`

**Остановить повторение** — Полностью останавливает текущее повторение.

- Работает с: Повторениями

```kotlin
stop_repeat()
```

#### `end_thread`

**Остановить последовательность** — Останавливает текущую последовательность блоков кода. Любой код после этого блока не будет выполнен.

- Если действие было использовано в функциях, то остановит родительскую строку, в которой вызвали функцию.

```kotlin
end_thread()
```

#### `skip_iteration`

**Пропустить повторение** — Пропускает одну итерацию в текущем повторении.

- Работает с: Повторениями

```kotlin
skip_iteration()
```
