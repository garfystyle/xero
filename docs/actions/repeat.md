## Повторение

#### `repeat.forever`

**Повторять вечно** — Постоянно повторяет код внутри поршней.

```kotlin
repeat.forever() { }
```

#### `on_circle`

**Проход по окружности** — Последовательно выдаёт местоположение каждого блока окружности с указанными параметрами.

```kotlin
on_circle(x, loc(0, 64, 0), 1, 1, vec(0, 1, 0), 1) { }
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `variable` | переменная | Для присвоения местоположения |
| `center` | местоположение | Центр окружности |
| `radius` | число | Радиус круга |
| `circle_points` | число | Количество точек круга |
| `perpendicular_to_plane` | вектор | Нормаль плоскости, к которой окружность будет перпендикулярна |
| `start_angle` | число | Начальный угол |
| `angle_unit` | маркер | Тип угла:<br>`degrees` Градусы<br>`radians` Радианы |

#### `on_path`

**Проход по пути** — Проходит от одного местоположения к другому с определённым шагом, присваивая текущее местоположение в указанную переменную.

```kotlin
on_path(x, 1, loc(0, 64, 0)) { }
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `variable` | переменная | Для присвоения местоположения |
| `step` | число | Расстояние между точками |
| `locations` | местоположение, до 21 | Местоположения концов прямых |
| `rotation` | маркер | Сохранять поворот указанного местоположения:<br>`true` Сохранять<br>`false` Не сохранять |

#### `on_grid`

**Проход по региону** — Выдаёт местоположение каждого блока из заданного региона в указанную переменную.

```kotlin
on_grid(x, loc(0, 64, 0), loc(0, 64, 0)) { }
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `variable` | переменная | Для присвоения текущего местоположения региона |
| `start` | местоположение | Начальное местоположение |
| `end` | местоположение | Конечное местоположение |

#### `for_each_map_entry`

**Проход по словарю** — Обращается к каждому элементу из указанного словаря и выдаёт его индекс и значение в указанные переменные.

```kotlin
for_each_map_entry(x, x, {"a": 1}) { }
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `key_variable` | переменная | Переменная для присвоения ключа элемента |
| `value_variable` | переменная | Переменная для присвоения значения элемента |
| `map` | словарь | Словарь, по которому необходимо проходиться |

#### `adjacently`

**Проход по смежным блокам** — Присваивает текущее местоположение в указанную переменную среди соседних блоков относительно заданного местоположения.

```kotlin
adjacently(x, loc(0, 64, 0)) { }
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `variable` | переменная | Для присвоения местоположения |
| `origin` | местоположение | Центральный блок |
| `change_rotation` | маркер | Поворачивать направление взгляда элемента относительно местоположения:<br>`true` Поворачивать<br>`false` Не поворачивать |
| `include_self` | маркер | Учитывать центральный блок:<br>`true` Учитывать<br>`false` Не учитывать |
| `pattern` | маркер | Тип выбора смежных блоков:<br>`cardinal` Кардинальный<br>`square` Квадратный<br>`adjacent` Примыкающий<br>`cube` Кубический |

#### `for_each_in_list`

**Проход по списку** — Обращается к каждому элементу из указанного списка и выдаёт его индекс и значение в указанные переменные.

```kotlin
for_each_in_list(x, x, [1, 2]) { }
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `index_variable` | переменная | Для присвоения индекса элемента |
| `value_variable` | переменная | Для присвоения значения элемента |
| `list` | список | Список, по которому необходимо проходиться |

#### `on_sphere`

**Проход по сфере** — Последовательно выдаёт местоположение каждой точки на сфере с указанными параметрами.

```kotlin
on_sphere(x, loc(0, 64, 0), 1, 1) { }
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `variable` | переменная | Текущее местоположение точки на сфере |
| `center` | местоположение | Центр сферы |
| `radius` | число | Радиус сферы |
| `points` | число | Количество точек |
| `rotate_location` | маркер | Направление местоположения у точек:<br>`no_changes` Как в местоположении<br>`inwards` К центру<br>`outwards` От центра |

#### `on_range`

**Цикл в диапазоне** — Присваивает текущее число в указанную переменную из заданного диапазона с определённым шагом.

```kotlin
on_range(x, 1, 1, 1) { }
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `variable` | переменная | Текущее число из диапазона |
| `start` | число | Нижняя граница диапазона |
| `end` | число | Верхняя граница диапазона |
| `interval` | число | Шаг |

#### `multi_times`

**Цикл со счётчиком** — Выполняет код заданное количество раз.

```kotlin
multi_times(x, 1) { }
```

| Аргумент | Вид | Описание |
|:--|:--|:--|
| `variable` | переменная | Текущее значения счетчика |
| `amount` | число | Количество выполнений кода |

#### `repeat.while`

**Цикл с условием** — Выполняет код до тех пор, пока выбранное условие является истиной.

```kotlin
repeat.while(x == 1) { }
```
