## Событие игрока

### События мира

| Событие | В игре | Что значит | Отменяемое |
|:--|:--|:--|:-:|
| `player_custom_click` | Игрок вызывает кастомный клик | Выполняет код, когда игрок вызывает кастомный клик в диалоговом окне или чате. |  |
| `player_quit` | Игрок вышел из мира | Выполняет код, когда игрок выходит из мира. |  |
| `player_ask_gamemode_change` | Игрок запросил меню смены режима игры | Выполняет код, когда игрок запрашивает меню смены режима игры.<br>По умолчанию, это событие отменяется, если игрок не имеет доступа к смену режима.<br>Работает с: Комбинацией клавиш F3 + F4, Комбинацией клавиш F3 + N | ✓ |
| `player_request_stats` | Игрок запросил статистику | Выполняет код, когда игрок открывает меню "Статистика".<br>Закрыть меню "Статистика" можно действием "Закрыть меню". |  |
| `player_join` | Игрок зашёл в мир | Выполняет код, когда игрок заходит в мир. |  |
| `player_rejoin` | Игрок перезашёл в мир | Выполняет код, когда игрок перезаходит в мир с помощью команды /play. | ✓ |
| `player_chat` | Игрок пишет сообщение в чат | Выполняет код, когда игрок пишет сообщение в чат. | ✓ |
| `player_currency_transaction` | Игрок совершает транзакцию | Выполняет код, когда игрок совершает транзакцию в изумрудах. |  |
| `player_skin_change` | Скин игрока изменился | Выполняет код, когда скин игрока меняется.<br>По умолчанию, это событие отменено.<br>Работает с: Действием "Установить скин", Самостоятельной сменой скина (через /skin) | ✓ |
